# Book Store

Projeto de uma loja virtual de livros desenvolvido com foco em praticar conceitos de desenvolvimento Front-End e criação de interfaces modernas e responsivas.

## Sobre o projeto

O Book Store apresenta uma interface de e-commerce para exibição e navegação por livros, utilizando uma estrutura simples e organizada.

## Tecnologias

* HTML5
* CSS3
* JavaScript

## Objetivo

Praticar desenvolvimento Front-End, estilização de interfaces, responsividade e interações com JavaScript.
